# Nexus Sight

Predicts the win probability of a professional League of Legends game from the two teams and their draft,
using Elo ratings, player ratings, recent form and draft features trained on 12,000 pro games (2018–2025).

Source code and evaluation: https://github.com/Zylocope/LOL-game-analyzer
